# Internationalization / Internazionalizzazione

## Italiano

Il frontend supporta Italiano e Inglese.

La lingua viene scelta in questo ordine:

1. `hass.locale.language` quando l'app è eseguita dentro Home Assistant;
2. `navigator.language` quando l'app è eseguita nella demo standalone.

Le lingue `it-*` usano l'Italiano; le altre lingue usano attualmente l'Inglese come fallback.

Le stringhe del frontend sono in `src/i18n.ts`. Le stringhe della custom integration Home Assistant rimangono invece in `strings.json` e `translations/`.

---

## English

The frontend supports Italian and English.

Language selection follows this order:

1. `hass.locale.language` when the application runs inside Home Assistant;
2. `navigator.language` when the standalone demo is running.

Locales matching `it-*` use Italian; all other locales currently fall back to English.

Frontend strings live in `src/i18n.ts`. Home Assistant custom-integration strings remain in `strings.json` and `translations/`.
