# Internationalization / Internazionalizzazione

Release baseline: **v2.0.0**.

## Italiano

Family Calendar supporta **Italiano** e **Inglese**.

### Selezione lingua

Dentro Home Assistant la lingua viene letta da `hass.locale.language`. Le locale `it-*` usano l'Italiano; le altre usano attualmente l'Inglese come fallback.

La demo standalone usa intenzionalmente `it-IT` per rendere deterministici sviluppo e test visuali.

### Dove vivono le stringhe

Frontend:

```text
src/i18n.ts
```

Custom integration:

```text
custom_components/family_calendar/strings.json
custom_components/family_calendar/translations/
```

Le label del catalogo icone vivono in `src/entity-icon-customization.tsx` e devono sempre fornire sia `it` sia `en`.

### Regole

- ogni nuova stringa riutilizzabile deve preferire una chiave i18n;
- ogni icona deve avere label IT/EN e keyword utili alla ricerca;
- nomi propri di prodotti, per esempio Apple TV o HomePod, possono restare invariati dove appropriato;
- date e orari devono usare `Intl` / `toLocaleDateString` / `toLocaleTimeString`;
- stati Home Assistant mostrati all'utente devono essere tradotti quando esiste una forma localizzata.

## English

Family Calendar supports **Italian** and **English**.

### Language selection

Home Assistant language is read from `hass.locale.language`. `it-*` locales use Italian; other locales currently fall back to English.

The standalone demo intentionally uses `it-IT` for deterministic visual development/testing.

### String locations

Frontend:

```text
src/i18n.ts
```

Custom integration:

```text
custom_components/family_calendar/strings.json
custom_components/family_calendar/translations/
```

Icon-catalog labels live in `src/entity-icon-customization.tsx` and must always provide both `it` and `en`.

### Rules

- prefer reusable i18n keys for reusable UI copy;
- every icon must have IT/EN labels and useful search keywords;
- product proper names such as Apple TV or HomePod may remain unchanged when appropriate;
- format dates/times with `Intl` / locale-aware APIs;
- translate Home Assistant state labels before rendering when a localized form exists.
