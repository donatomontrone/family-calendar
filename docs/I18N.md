# Internationalization / Internazionalizzazione

## 🇮🇹 Italiano

Il frontend supporta Italiano e Inglese. Lo starter seleziona automaticamente:
- `it-*` → Italiano
- qualsiasi altra lingua → English

In una fase successiva la selezione potrà essere collegata direttamente alla lingua configurata in Home Assistant.

## 🇬🇧 English

The frontend supports Italian and English. The starter automatically selects:
- `it-*` → Italian
- any other locale → English

Later, the language selection can be connected directly to the language configured in Home Assistant.
